Frequently Asked Questions

Answers to common questions about EasyGrader.

Is this secure?

The application implements authentication and authorization to ensure only authorized users can access specific features. Uploaded code is processed in an isolated environment, inputs are validated, and the database is protected against unauthorized access using secure configurations.

Can it support multiple programming languages?

Yes. The system supports running code written in multiple programming languages using isolated execution environments, ensuring safe and accurate testing for each language.

Can students run tests without submitting?

Yes. If the professor enables it, public test cases can be run independently so students can validate their code before final submission.

Does EasyGrader store submission history?

Every submission is saved with a timestamp, allowing instructors and students to track progress and deadlines.

Who can view my submitted code?

Only the student and authorized instructors can view submitted code.

Can students resubmit assignments?

Yes. Students may resubmit assignments before the deadline if resubmissions are allowed by the instructor.

Are late submissions allowed?

Late submission policies depend on the assignment settings configured by the professor.

Are both public and private test cases supported?

Yes. Public test cases may be used for practice, while private test cases are used for final evaluation.

What happens if my code fails to compile?

The system displays compilation or runtime errors to help students debug their code.

Is there a time limit for code execution?

Yes. Programs are subject to execution time limits to ensure fair use of system resources.
