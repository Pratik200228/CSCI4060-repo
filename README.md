# Project Name: EasyGrade

A web-based application that allows users to submit code and automatically evaluates it against predefined test cases.

## Description

This project is a web application designed to evaluate user-submitted code by running it against predefined test cases on the backend.  
It is useful for learning platforms, coding practice, and automated assessment systems.

## Features

- User-friendly web interface
- Supports multiple programming languages
- Secure backend execution of code
- Automatic test case validation
- Displays pass/fail results with feedback
